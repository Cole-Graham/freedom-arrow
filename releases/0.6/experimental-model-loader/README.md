# Optional model loader test

Optional FAModels 0.2.0 source for local model replacements and unit-scoped infantry weapon previews. This DLL is not part of the main package. Model files and configuration are installed separately.

The rifle prototype targets unit 901 only. It attaches static weapon meshes to the existing native weapon object; it creates no skeleton, skin weights or new animation rig. Native weapon stats remain unchanged. Grip, effects, pooling and battle visibility require game tests. Source compiles against the generated game assemblies.
