FREEDOM ARROW — DEDICATED BUILD 45 LAUNCHER (WINDOWS)

This folder includes the exact published Freedom Arrow gameplay dev.45.
The launcher does not download newer gameplay builds. Keep this whole folder.

1. Close Broken Arrow completely. Keep Steam open and signed in.
2. Right-click the downloaded ZIP and choose Extract All, then Extract.
3. Open the extracted FreedomArrow-Launcher-dev45 folder.
4. Double-click BAModLauncher.exe.
5. If Broken Arrow is not found, click Settings and select the folder containing
   BrokenArrow.exe. Return to the main launcher window.
6. Click PLAY. Wait while the launcher checks MelonLoader and installs dev.45.
   The first start can take several minutes. Internet is needed for MelonLoader
   if it is not installed or needs updating.
7. At the game's main menu, verify the version is 0.7.0-dev.45.

Do not move just the EXE out of this folder: it needs the included .bamod.
Do not unzip the .bamod. The launcher imports it for you.
The Play vanilla button uses BAModLauncher's normal no-mod launch path.

Models and Music/Voices are a separate download in #build-install. Existing
shared assets stay installed. Install that pack through BAModManager for custom
models/music/voices; this ZIP includes gameplay only. Linux users should follow
#build-install's existing Linux instructions.
